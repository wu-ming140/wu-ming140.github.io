## 一、函数重载
在**同一个作用域**内，可以定义**多个同名函数**，只要它们的**参数列表不同**。编译器会根据调用时传入的实参，自动选择最匹配的那一个。
~~~
#include <iostream>

void print(int x)        { std::cout << "int: "    << x << "\n"; }
void print(double x)     { std::cout << "double: " << x << "\n"; }
void print(const char* s){ std::cout << "str: "    << s << "\n"; }
void print(int a, int b) { std::cout << "two: "    << a << "," << b << "\n"; }

int main() {
    print(42);          // 调用 print(int)
    print(3.14);        // 调用 print(double)
    print("hello");     // 调用 print(const char*)
    print(1, 2);        // 调用 print(int, int)
}
~~~
### （一）重载的三种情况
参数个数   参数类型    参数顺序
无法通过返回值和不同的函数名区分   
加不加const也不区分
但是用引用/指针指向的对象const是重载的
~~~
void g(int&);
void g(const int&);  
~~~
起别名typedef和using也不产生新类型
**那define呢**  宏定义   是在编译前做的文本替换  谈不上重载  
宏和同名函数相遇时候也不会触发重载   而是直接破坏代码
**（ai拓展）**重载是**编译器**根据类型做的事；宏在**预处理器**阶段就已经被替换掉了，编译器根本没见过宏的名字**
宏没有作用域  调试器看不到宏
~~~
#define f(x) (x + 1)          // 先定义了宏

void f(int x);               //  展开成 void (x + 1);  —— 语法错误
void f(double x);            //  报错

f(1);                        // 展开成 (1 + 1)，到不了重载决议
~~~

### （二）怎么选择函数
**匹配**（含类型相同、数组/函数退化为指针、忽略顶层 const）
**提升转换**：`char/short → int`、`float → double`
**标准转换**：`int → double`、`double → int`、指针 → `bool`
还有手动构造函数什么的
**还有歧义调用**long和double    如果传1  int到两种都是标准的转换，没办法调用（没有优先级顺序

### （三）在类中的const成员函数重载（ai拓展）
~~~
class Array {
public:
    int&       operator[](size_t i)       { return data[i]; }  // 非 const 对象用
    const int& operator[](size_t i) const { return data[i]; }  // const 对象用
private:
    int data[10];
};
~~~
`const` 对象会自动选 `const` 版本，非 const 对象优先选非 const 版本。

c++11开始  有引用限定符（ai拓展）
~~~
void f() &;    // 只能对左值调用
void f() &&;   // 只能对右值调用
~~~
不要让带默认参数的函数和另一个重载函数在"省略参数"时能匹配上。（ai拓展）
~~~
void f(int a);
void f(int a, int b = 0);

f(1);   //  歧义：两个都能匹配
f(1,2); //  调用第二个
~~~

## 二、递归调用    是在栈上的操作
**要注意栈溢出的风险**
要加上一个不递归直接返回结果时的情况
写递归时，base case 要"宽一点"更安全。
~~~
// 阶乘 n! = n * (n-1)!
long long factorial(int n) {
    if (n <= 1) return 1;        // 基本情况
    return n * factorial(n - 1); // 递归步骤：规模从 n 缩到 n-1
}
~~~
以 `factorial(4)` 为例，**每次调用都会在栈上压入一个新的栈帧**，里面存参数、局部变量、返回地址
有一个回溯的过程
往下递归的时候要一步步压栈    回溯的时候要一个个弹出来
类似嵌套循环  
（ai拓展）
**递归深度 = 同时存在的栈帧数。** 深度太大会**栈溢出（stack overflow）**，不是逻辑错误，是运行时崩溃。
~~~
线性递归   阶层、求和。字符串反转
int sum(int n)
{
	if(n<=0)
	{
		return 0;
	}
	return n+sum(n-1);//1+2+3+到n累加
}

~~~

~~~
这里是ai拓展的另一个辅助理解的
void print_reverse(const std::string& s, std::size_t i = 0) {
    if (i == s.size()) return;      // 1. 走到底了就停
    print_reverse(s, i + 1);        // 2. 先不管，继续往下走（压栈）
    std::cout << s[i];              // 3. 走到底了，再开始打印（弹栈）
}    //    深入执行依次就压一次栈   回溯一次就弹栈
~~~

**汉诺塔**问题    每次只能移动一个盘子，大盘子不能压在小盘子上
用一个函数去模拟汉诺塔的移动一次盘子从起始点到目标点的过程
**这里一个用到递归的思路**  要移动第n个盘子，要把上面n-1个盘子移到中间区域  一步步用递归深入，移动完后最后剩下我们要的第n个盘子（回溯到这里）
然后把盘子移动  再把刚刚递归存的n-1个盘子递归移动到目标点上

~~~
void hannuota(int n,char from,char mid,char to)
{
	if(n==0)
	{
		return;
	}
	hannuota(n-1,from,to,mid);//把上面盘子从from到mid柱子
	
	std::cout<<"移动"<<from<<"到"<<to<<endl;//   这里只是提示一下盘子移动了
	//上面递归后，接下来回溯回来就是我们要的第n个盘子  直接
	hannuota(n-1,mid,from,to);//把剩下的移动了
	//暂存在mid上的那 `n-1` 个盘子，移动到to上
}
~~~
### 递归数据结构  树的遍历
~~~
struct node{
	int value;
	node* left=nullptr;
	node* right=nullptr;
};

void bianli(const node* root)
{
	//传入根结点  遍历
	if(!root)
	{
		return;//空树
	}
	bianli(root->left);
	//一次次往左子树递归深入
	std::cout<<root->value<<endl;
	bianli(root->right);//再递归右子树
	//直到根结点的全部左右子树遍历完，就剩下根结点了  回到if  return结束
}
~~~

### lambda函数(这部分ai辅助学)
一个完整的 Lambda 长这样：
~~~
[捕获列表] (参数列表) mutable -> 返回类型 { 函数体 }
~~~
**捕获列表[]**
**Lambda 最牛逼的地方**在于：它可以读取或修改**它所在的那个外层函数（比如 `main`）里的局部变量**。普通函数只能靠传参

#### 空捕获 `[]`
不抓取任何外部变量
~~~
int x = 10;
auto f = []() { 
     cout << x; // 抓不到 x
};
~~~
#### 按值捕获 `[=]` 或 `[x]`
把外面的变量**复制**一份拿进来用（只读）
~~~
int x = 10;
auto f = [x]() { // 或者写 [=] 表示捕获所有外部变量
    std::cout << x; 
};
x = 20;
f(); // 依然输出 10，因为抓进来的是副本
~~~
#### 按引用捕获 `[&]` 或 `[&x]`，直接把外面变量的**引用**（真身）抓进来。可以在里面修改它
~~~
int x = 10;
auto f = [&x]() { // 或者写 [&] 表示引用捕获所有外部变量
    x = 99; 
};//声明函数
f();//调用函数
std::cout << x; // 输出 99
~~~
#### 混合捕获
`[=, &x]`：除了 `x` 按引用，其他都按值。  
`[&, x]`：除了 `x` 按值，其他都按引用。
ps：如果用 `[&]` 按引用捕获，千万注意 Lambda 的生命周期
    不要超过被引用变量的生命周期（否则会发生悬垂引用，导致程序崩溃）
    按值 `[=]` 通常更安全，但会有拷贝开销。
#### `mutable` 关键字
如果是按值 `[x]` 捕获，默认是**只读**的。如果你想在函数体里修改这个副本，需要加 `mutable`：
~~~
int x = 10;
auto f = [x]() mutable {
    x++; // 允许修改副本，但外面的 x 依然是 10
};
~~~
ai：**Lambda 根本不是“函数”，它本质上是一个“匿名类（结构体）--或者说是类和对象”的对象**
本来他这里是说结构体

**在 C 语言里，struct 只能包含数据，不能包含函数。  
但在 C++ 里，class和 struct 几乎是一模一样的**

**区别：（ai）
~~~
默认访问权限：class 的成员默认是 private（私有），struct 的成员默认是 public（公有）。
 默认继承权限：class 默认是私有继承，struct默认是公有继承
在c++中：
struct 也可以有构造函数、析构函数、成员函数，也可以继承、也可以多态。所以，在 C++ 里写 struct 本质上就是在写一个类（只不过成员默认公开而已）
~~~

现代c++（c++14起）
**泛型lambda
参数列表里可以使用 `auto`，这相当于一个**函数模板
~~~
auto add = [](auto a, auto b) {
    return a + b;
};
std::cout << add(1, 2);     
std::cout << add(1.5, 2.5); 
~~~
**初始化捕获（常用于移动语义。？
可以将外部变量“移动”进 Lambda 里，或者给捕获的变量起个新名字
~~~
auto ptr = std::make_unique<int>(10);
// 把 ptr 的所有权转移到 Lambda 内部
auto f = [p = std::move(ptr)]() {
    std::cout << *p;//   这里move就是转移所有权
};
~~~
实际用途（ai了解）：
1. 延长生命周期**：如果你用引用捕获 `[&ptr]`，如果外面的 `main` 函数运行完了，`ptr` 被销毁，Lambda 里的引用就变成了野指针（悬垂引用），一运行就崩溃。通过“移动捕获”，Lambda 直接把资源据为己有，只要 Lambda 对象 `f` 还在，内存就绝对安全。
    
2. **多线程/异步任务**：如果你要把一个 Lambda 丢给后台线程去执行，你肯定希望这个 Lambda 自己带好它需要的资源（比如 `unique_ptr`），而不是依赖外面的变量。
    
3. **不仅可以捕获已有的变量，还能造新变量**：比如 `[x = 1, y = x + 1]`，你可以直接在 `[]` 里面写表达式来初始化变量。
