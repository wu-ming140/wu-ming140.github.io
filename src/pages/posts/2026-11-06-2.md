相当于日常的分文件写代码。？
**声明和定义**
math.h头文件:   只声明   有这个东西
math.cpp源文件:具体实现代码    定义
main.cpp  主程序   使用写好的库
在main中调用的时候
前面加#include "math.h"
然后可以直接调用函数
呃呃放示例吧
~~~
头文件math.h
// 必须加上这句，防止头文件被重复包含
#pragma once 

int add(int a, int b); //声明


源文件math.cpp
#include "math.h" // 必须头文件，让编译器检查声明和定义是否一致

int add(int a, int b) {
    return a + b;
}


主程序main.cpp
#include <iostream>
#include "math.h" // 把 math 的“目录”引进来，这样 main 才知道有 add 这个函数

int main() {
    std::cout << add(2, 3) << std::endl; // 调用 add
    return 0;
}
~~~

## 模块一 类的基础和封装
**类和对象**
类  ： 规定了一个东西的数据/属性  和能干嘛
对象： 根据类做的东西

关键字：class
和struct区别
基本一样  class默认私有  private  struct默认公有public

**核心特性：封装**
private和public
外界可以通过public里的东西去操作private的数据
间接访问
否则的话在外界就可以随意改数据，好像没有这两个之分和结构体区别不大

**可以在类class内部定义函数**
~~~
class student{
private:
	int score;
public:
	int getscore()const{//加const表示只读  不能修改
	//不过不加const也没问题
	//只是实际开发  只要这个函数不改成员变量  就要加const
	
		return score;//在public里间接访问了private的内容
	}
}
~~~
**this指针**
指向当前正在调用这个函数的对象
**常用于解决命名冲突**
示例
~~~
class Student {
private:
    std::string name;
public:
    // 参数叫 name，成员变量也叫 name，怎么区分？
    void setName(std::string name) {
        this->name = name; // this->name 是成员变量，后面的 name 是参数
    }
};
~~~

**Getter和Setter**
封装标配
变量设private后   外界就不可以直接读写
Getter只读   Setter只写

或者说  private表示私人的，外界不能直接访问的
public是公有的  外界只能通过这个地方访问数据
