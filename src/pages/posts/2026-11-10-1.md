## this
**参数和成员变量同名怎么区分**
**同名时，直接写名字会优先使用参数**
之前这样写没有歧义
```
class Student {
    private int score;

    public void setScore(int newScore) {
        score = newScore;
    }
}
```
但如果把参数也叫 `score`：
```
public void setScore(int score) {
    score = score;
}
```
就变成了**把参数赋值给参数自己**，没有修改对象的成员变量。
它能编译，所以容易漏掉这个错误。

**this.score表示当前对象的成员变量**
```
public void setScore(int score) {
    this.score = score;
}
```

```
this.score // 当前对象的成员变量
score      // 本次调用传进来的参数
```

例如：
```
Student s = new Student();
s.setScore(85);
```
调用 `s.setScore(85)` 时：
- 参数 `score` 的值是 `85`。
- 方法中的 `this` 引用的就是 `s` 所引用的那个对象。
- `this.score = score` 把该对象的成绩改成 `85`。
**`this` 随调用方法的对象而确定**
```
Student s1 = new Student();
Student s2 = new Student();

s1.setScore(85);
s2.setScore(92);
```
执行第一句调用时，`this` 引用 `s1` 对应的对象；执行第二句调用时，`this` 引用 `s2` 对应的对象。
因此，两个对象可以各自保存不同的成绩。
把校验也加回来：
```
class Student {
    private int score;

    public void setScore(int score) {
        if (score >= 0 && score <= 100) {
            this.score = score;
        } else {
            System.out.println("成绩必须在0～100之间");
        }
    }

    public int getScore() {
        return this.score;
    }
}
```
`getScore()` 中没有同名局部变量或参数，所以这里也可以简写为：
```
return score;
```
**`static` 方法中不能直接使用 `this`**
`this` 代表当前对象，而 `static` 方法的调用不要求有一个当前对象。
`main` 中这样写会报错：
```
public static void main(String[] args) {
    System.out.println(this.score); // 编译报错
}
```
仍然通过创建对象来调用实例方法：
```
Student s = new Student();
s.setScore(85);

System.out.println(s.getScore());
```

**测试**

判断一下下面的代码。这里故意漏写了 `this`：
```
class Student {
    private int score;

    public void setScore(int score) {
        score = score;
    }

    public int getScore() {
        return score;
    }
}
```
在 `main` 中：
```
Student s = new Student();
s.setScore(85);

System.out.println(s.getScore());
```
最后输出的是0   因为setscore没有修改对象的成员变量
在方法里直接写score   指的是参数  这里相当于参数给自己赋值了
执行过程是：
1. 创建对象，成员变量 `score` 默认是 `0`。
2. 调用 `setScore(85)`，参数得到 `85`。
3. 参数给自己赋值，成员变量仍然是 `0`。
4. `getScore()` 返回成员变量，因此输出 `0`。

改成下面这样，才会输出 `85`：
```
public void setScore(int score) {
    this.score = score;
    // 对象的成员变量 = 传入的参数
}
```
**`this.score` 和参数 `score` 是两个不同的变量。**

## 构造方法
**创建对象时  把初始数据设置好**
之前创建学生对象，需要先创建，再赋值：
```
Student s = new Student();
s.setName("小明");
s.setAge(18);
```
通过构造方法，可以写成：
```
Student s = new Student("小明", 18);
```
**代码实现**
~~~
class student{
	private String name;
	private int age;
	public student(String name,int age)
	{
		this.name=name;
		this.age=age;
		
	}
	public void show()
	{
		System.out.println("姓名"+name+"年龄"+age);
	}

}
~~~

public Student(String name, int age)
构造方法有两个语法特点：
- **名字必须与类名完全相同**，这里是 `Student`。
- **不写返回值类型，连 `void` 也不写。**
因此，下面这个是普通方法，不是构造方法：

```
public void Student(String name, int age) {
    // 因为写了 void，所以这是普通方法
}
```
**创建对象时，调用对应的构造方法**
```
Student s = new Student("小明", 18);
```
执行时：
1. 创建一个 `Student` 对象，成员变量先具有默认值。
2. 调用构造方法，参数 `name` 得到 `"小明"`，参数 `age` 得到 `18`。
3. 构造方法通过 `this` 修改新对象的成员变量。
4. 创建完成后，把对象引用赋给 `s`。
这里：
```
this.name = name;
```
仍然表示：
```
新对象的 name 成员变量 = 本次传入的 name 参数
```
构造方法负责初始化，**它本身不通过 `return` 返回对象**。
**为什么之前没写构造方法，也能 `new Student()`？**
如果一个类**没有声明任何构造方法**，编译器会自动提供一个无参构造方法。

但当你自己写了：
```
public Student(String name, int age) {
    this.name = name;
    this.age = age;
}
```
编译器就不再自动提供无参构造方法。此时：
```
new Student("小明", 18); // 正确
new Student();          // 编译报错：没有对应的无参构造方法
```
如果还想保留无参创建，就需要自己再写一个无参构造方法。这涉及**构造方法重载**

**代码训练**
~~~
class Phone{
    private String brand;//平牌
    private double price;//价格
    public Phone(String brand,double price)//方法构造
    {
        this.brand=brand;
        this.price=price;
    }
    public void show()
    {
        System.out.println("品牌:"+brand+"价格:"+price);
    }
}
public class study01{
    public static void main(String[] args)
    {
        Phone p=new Phone("华为",9999);
        p.show();//调用方法
    }
}
~~~
传入的 `9999` 是 `int`，参数 `price` 是 `double`，这里会发生**自动类型转换**，所以可以直接传入，输出时显示为 `9999.0`。

**构造方法重载**
刚才只写了这个构造方法：
```
public Phone(String brand, double price)
```
所以创建对象时，需要提供品牌和价格：
```
new Phone("华为", 9999);
```
如果希望下面两种写法都能用：
```
new Phone();
new Phone("华为", 9999);
```
就需要定义两个参数列表不同的构造方法。

**构造方法也可以重载**
例如：
```
public Phone() {
    this.brand = "未知品牌";
    this.price = 0;
}

public Phone(String brand, double price) {
    this.brand = brand;
    this.price = price;
}
```
创建时，根据传入的参数选择：

|创建方式|调用哪个构造方法|
|---|---|
|`new Phone()`|无参构造方法|
|`new Phone("华为", 9999)`|两个参数的构造方法|

这和普通方法重载的判断思路相同：**看参数列表。**
**`this(...)`：调用本类的另一个构造方法**
上面两个构造方法都在给品牌和价格赋值，可以把无参构造方法改成：
```
public Phone() {
    this("未知品牌", 0);
}
```

意思是：**使用本类接收品牌、价格的构造方法，完成当前对象的初始化。**


**完整**
~~~
class Phone {
    private String brand;
    private double price;

    public Phone() {
        this("未知品牌", 0);
    }

    public Phone(String brand, double price) {
        this.brand = brand;
        this.price = price;
    }

    public void show() {
        System.out.println("品牌：" + brand + "，价格：" + price);
    }
}
~~~

**区分两种 `this` 写法**
```
this.brand
```
表示：当前对象的 `brand` 成员变量。
```
this("未知品牌", 0);
```
表示：调用本类中参数匹配的构造方法。

执行：
```
new Phone();
```
时，调用过程是：
```
无参构造方法
    ↓ this("未知品牌", 0)
双参数构造方法，给成员变量赋值
    ↓ 返回
无参构造方法执行结束
```
**这个过程只创建一个对象。** `this(...)` 是让另一个构造方法继续初始化同一个对象，没有再次创建对象。

this("未知品牌", 0)相当于再次调用了有参数的Phone
**调用的是这个有参数的构造方法**：
```
public Phone(String brand, double price) {
    this.brand = brand;
    this.price = price;
}
```
因此：
```
this("未知品牌", 0);
```
会把 `"未知品牌"` 传给 `brand`，把 `0` 传给 `price`，让它完成赋值。
完整过程是：
```
new Phone()
    → 进入无参构造方法
    → this("未知品牌", 0)
    → 进入双参数构造方法，给成员变量赋值
    → 返回无参构造方法
    → 初始化完成
```
**始终是同一个对象**。这里是在构造方法之间调用，没有再次执行 `new`，所以不会创建第二个对象


## static 静态成员

**区分：每个对象自己的数据，与整个类共享的数据**
手机的品牌、价格，每部手机可以不同：
```
private String brand;
private double price;
```
如果想记录“总共创建了多少个手机对象”，就需要一个共享的计数器：
```
private static int count = 0;
```
`static` 修饰的成员变量属于类，所有对象共享这一份。

| 成员              | 含义             |
| --------------- | -------------- |
| `brand`、`price` | 每个对象各自保存       |
| `static count`  | 整个 `Phone` 类共享 |
创建对象时，让共享计数器加一
~~~
class Phone{
	private String brand;
	private double price;
	
	private static int count=0;
	public Phone(){
		this("未知品牌",0);
	
	}

	public Phone(String brand,double price)
	{
		this.brand=brand;
		this.price=price;
		count++;
	}
	
	public void show()
	{
		System.out.println("品牌"+brand+"111"+price);
	}
	public static int getcount()
	{
		return count;
	}
}

~~~
每创建一个对象，计数加一。无参构造方法会转调双参构造方法，因此也会执行这句

```
public static int getCount()
```
这是一个**静态方法**，可以通过类名调用：
```
Phone.getCount();
```
**静态方法可以直接通过类名调用**
在 `main` 中运行：
```
System.out.println(Phone.getCount()); // 0

Phone p1 = new Phone();
Phone p2 = new Phone("华为", 9999);

System.out.println(Phone.getCount()); // 2

p1.show();
p2.show();
```
注意调用方式：
```
Phone.getCount(); // 静态方法，通过类名调用
p1.show();        // 实例方法，通过对象引用调用
```

**为什么静态方法里不能直接用 `this`？**
因为调用：
```
Phone.getCount();
```
时，甚至可以一个手机对象都没创建，所以这里没有一个“当前手机对象”供 `this` 引用。
同样，静态方法也不能直接访问某个对象的 `brand`：
```
public static void test() {
    System.out.println(brand); // 编译报错
}
```
要访问品牌，必须明确指定对象，例如通过参数：
```
public static void test(Phone phone) {
    System.out.println(phone.brand);
}
```
这段写在 `Phone` 类内部，所以可以访问它的私有成员。

**联系 `main`**
```
public static void main(String[] args)
```
`main` 是静态方法，因此程序启动时，可以先执行它，再由里面的代码创建对象。
