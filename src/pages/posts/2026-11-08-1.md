**对于除法   先看参与计算的数据类型** 
~~~
System.out.println(5 / 2);   // 2
System.out.println(5 / 2.0); // 2.5
~~~
注意下面这个容易写错的情况：
```
double result = 5 / 2;
System.out.println(result); // 2.0
```
顺序是：
```
先计算右边：5 / 2 → 整数 2
再赋给 double 变量：2 → 2.0
```
**左边用 `double` 接收，不会改变右边已经完成的计算。**
如果希望得到 `2.5`，可以这样：
```
double result = 5 / 2.0;
```
**类型转换：让整数参与浮点数计算**
如果操作数来自两个整数变量：
```
int a = 5;
int b = 2;
```
**下面涉及的其实是隐式转换和强制转换**
```
double result = (double) a / b;

System.out.println(result); // 2.5
```
```
(double) a → 5.0
5.0 / 2    → 2.5
```

**它不会修改变量 `a` 的类型或保存的值**，`a` 仍然是值为 `5` 的 `int` 变量。

转换的位置也有区别：
```
double x = (double) a / b;   // 2.5
double y = (double) (a / b); // 2.0
```

第二行先算括号里的整数除法，得到 `2`，再转成 `2.0`。
**隐式转换，也叫自动类型转换：**
```
int count = 10;
double number = count; // 自动从 int 转为 double   高转低
```
**强制转换：**
```
double score = 95.8;
int value = (int) score; // 明确要求转为 int，得到 95
```
这里需要记住的 Java 规则是：**`double` 不能直接赋给 `int`，必须显式转换，否则编译报错。**
```
int value = score;      // Java：编译错误    小不能直接转打  要强转一波
int value = (int) score; // 正确
```
**C 和 C++ 的普通赋值允许这种隐式转换，Java 在这里更严格。**
例如 C/C++：
```
double score = 95.8;
int value = score; // 允许隐式转换，value 得到 95
```
**是直接去除小数点后的东西**
必须明确写出转换：

int value = (int) score; // value 得到 95

## 比较运算和逻辑运算
**比较运算：结果是 `boolean`**
这些符号含义和 C/C++ 一样：

| 运算符       | 含义        |
| --------- | --------- |
| `>`、`<`   | 大于、小于     |
| `>=`、`<=` | 大于等于、小于等于 |
| `==`      | 是否相等      |
| `!=`      | 是否不相等     |
|           |           |

Java 中，比较结果是 **`true` 或 `false`**，可以存入 `boolean` 变量：
```
int score = 85;

boolean passed = score >= 60;

System.out.println(passed);      // true
System.out.println(score == 100); // false
```

```
boolean passed = score >= 60;
//先计算 `score >= 60`，得到 `true`，再赋给 `passed`。
```
注意两个区别：
```
score = 60;   // 赋值：把 score 改成 60
score == 60;  // 判断：score 是否等于 60
```
第二行只是演示表达式；实际使用时，把它放在输出、赋值或条件里：
```
System.out.println(score == 60);
```
**Java 不能把数字直接当作布尔值：**
```
boolean flag = 1;  // 编译报错
boolean flag = true; // 正确
```
因此，后面学 `if` 时，条件也必须是布尔表达式，不能像 C 那样写 `if (1)`。
**逻辑运算：组合多个条件**
常用的三个运算符：

|运算符|含义|成立条件|
|---|---|---|
|`&&`|并且|两边都为 `true`|
|`\|`|或者|至少一边为 `true`|
|`!`|取反|把 `true`、`false` 反过来|

例如，判断成绩是否在合法范围内：
```
int score = 85;
boolean valid = score >= 0 && score <= 100;
System.out.println(valid); // true
```
**不能写成数学里的连写形式：**
```
0 <= score <= 100 //不成立
```
判断成绩是否越界：
```
boolean invalid = score < 0 || score > 100;
```
也可以对“合法”取反：
```
boolean invalid = !valid;
```
这里的 `!` 是“不是”的意思。

**`&&` 和 `||` 会短路**
**左边已经决定结果，右边就不执行。**
```
int a = 10;
int b = 0;

boolean result = b != 0 && a / b > 2;

System.out.println(result); // false
```
执行过程是：
1. `b != 0` 得到 `false`。
2. `&&` 要求两边都成立，结果已经确定是 `false`。
3. 因此不会执行 `a / b`，避免了整数除以零的异常。
同理，`||` 左边为 `true` 时，也不会执行右边。
组合条件可以主动加括号，更清楚：
```
boolean result = (a >= 60 && b >= 60) || a == 100;
```
含义是：**两科都及格，或者第一科满分。**

**方法重载**

```
public static int sum(int a, int b) { ... }
public static int sum(int a, int b, int c) { ... }
public static double sum(double a, double b) { ... }
```

- **同一个类里，方法名相同、参数列表不同**，编译器自动挑合适的那个。
- **只有三点算"参数不同"**：个数不同、类型不同、**顺序不同**。
- **只看参数,返回值类型不同不算重载**（`int f()` 和 `double f()` 会编译报错）。
- **C 语言没有重载**,C 里要实现"不同参数个数"只能起不同名字（`sum2`、`sum3`）， 这是 Java 更方便的地方。

**参数传递（Java 只有"值传递"）**

- 基本类型传的是**值的副本**，方法里改它**不影响外面**；
- 引用类型传的是**地址的副本**，方法里改"它指向的内容"**会影响外面**， 但给它**重新赋一个新对象则不影响外面**。
- C 里可以传指针（地址）来"真正改到外面"，Java 是靠"传对象引用"达到类似效果。

**方法的内存执行过程（栈帧）**

- **每调用一个方法，就在栈里给它分配一块空间（栈帧）**，存它的参数和局部变量；
- **方法执行完，这块空间就销毁**——这就是"局部变量出了方法就没了"的原因； 也是"递归太深会栈溢出（`StackOverflowError`）"的原因。


明天开运行机制，内存，接面向对象
