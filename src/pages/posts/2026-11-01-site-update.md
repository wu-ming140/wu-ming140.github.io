这段时间，小站从一个放文章的地方，慢慢长出了更多角落：日常、学习、作品、爱好，还有从不同地方收到的来信。

趁这一轮调整告一段落，把从最初整理页面到现在的主要变化记下来。以后回头看，也能知道这个小站是怎样一点点搭起来的。

## 首页与大厅，合到一起了

最开始想把原来的“文章”划分得更清楚，于是整理出了五个专栏：

| 专栏 | 这里准备放什么 |
| --- | --- |
| 生活随笔 / 心得分享 | 日常片段、个人感想和生活中的体会 |
| 学习记录 / 学习心得 | 学习笔记、练习过程、知识整理和踩坑记录 |
| 作品集 | 做过的项目、小工具和成果展示 |
| 爱好 | 游戏、音乐、书影音，以及喜欢的各种事情 |
| 小站日志 | 小站的搭建、调整与使用记录 |

后来又把“首页”和“大厅”合并：现在打开小站，就能先看到介绍，再进入五个专栏，也可以直接往下浏览全部文章与作品。原来的文章链接继续保留。

## 留言与提问，有了更多入口

留言区除了通过 GitHub 提交的来信，也能收下我自己的留言，以及从微信、QQ、邮件或日常交流里收到的问题。

这些站外来信由我手动整理，填写昵称、来源、问题，再补上自己的回答，会集中出现在“其他渠道来信”里。这里记录的是整理后的内容，不会自动读取其他平台的聊天记录。

留言和回复分别保存，再由小站关联起来。提问没有公开回复时显示“待回答”，补上公开回复后就会显示“已回答”。也可以按全部、留言、提问、待回答和其他渠道筛选。

## 浏览量可以看到了

大厅和页脚增加了全站总浏览量，文章标题下可以看到当前文章的阅读次数。

目前使用 Vercount 记录页面访问次数。它统计的是浏览量，同一个人刷新页面也可能增加次数，不等同于访客人数，接入之前的历史访问也不能补回来。

本地预览会显示“预览不计数”；正式网站才请求统计。服务超时或网络不通时，会显示“暂不可用”，方便区分加载失败和真实的零次访问。

## 图片和视频，也能放进文字里

文章、作品、留言、提问和回复都可以插入图片、视频。既能引用站内文件，也能使用外部媒体文件的直链。

图片可以点击放大，按 Esc、点击空白处或关闭按钮返回。视频会显示带播放控件的播放器，不会自动播放。

作品集另外补上了封面、简介和标签组成的展示卡片，大厅也有了最近作品的橱窗。没有上传封面的作品会使用文字封面，之后可以再慢慢补图。

## 有了自己的写作台

页脚加入了“写作台”。现在可以在网页里写文章、整理提问、回复来信，选择本机图片和视频，也能拖入文件、粘贴截图或插入媒体网址，边写边预览。

写作台提供两种保存与发布方式：

- 下载完整草稿包，包含正文和本次使用的新附件，放回本地博客文件夹后提交发布。
- 连接自己的 GitHub 仓库，检查内容后直接发布，正文和新附件会一起保存。

编辑中的文字、栏目设置与附件会自动保存到当前浏览器，刷新后可以恢复。这里只保留一份当前草稿，多份内容需要分别下载保存；本机草稿也不会自动同步到其他设备。

连接仓库后，还可以载入已有文章、留言和回复继续编辑。发布凭证仅用于当前页面连接，刷新后需要重新输入，不会放进草稿包。

## 找内容和读长文，更方便了

这一轮补上了站内搜索、标签和文章目录。

搜索可以查标题、简介、正文、专栏和标签，也包括公开留言、提问和公开回复；还可以按内容类型筛选。未公开的草稿不进入搜索。

标签让不同专栏里有关联的文章能聚在一起。正文使用二级、三级标题时会生成目录，电脑上可以在旁边查看，手机上可以展开使用。

文章和来信详情下方也增加了上一篇、下一篇和相关内容。相关推荐会参考同合集、同标签，以及同专栏或同类型的内容。

## 置顶与精选，按板块分别整理

置顶、精选现在可以用于文章、作品、留言和提问，各板块分别设置。

比如，一篇学习笔记可以只放进学习专栏的置顶栏目，也可以单独加入大厅精选；一条问题也能只在“提问”里置顶。每个板块都有自己的独立展示栏目，普通列表仍保留完整内容。

取消对应勾选，或点击“清除此板块标记”，重新发布后就会取消。修改一个板块的设置，不会影响其他板块。

## 合集、归档和订阅，也安排上了

“合集”用来整理有先后关系的内容。填写同一个合集名称，再设置各自的顺序号，就能组成一条阅读路线。一个合集可以跨专栏，也可以混合文章、留言和提问，详情页会显示当前项和合集上一项、下一项。

年月归档做成了可选择的浏览方式：默认仍按普通列表展示，需要时再切换成“按年月归档”，也可以选择最新或最早在前。切换排序不会改变置顶、精选栏目。

页脚的 RSS 入口提供三份订阅源：全站动态、文章与作品、留言与问答。每份收录最近 50 项公开内容，方便按自己的阅读习惯订阅。

## 发布之前，多一道检查

写作台新增了“发布前检查”，不连接仓库也可以先检查必要信息、媒体说明、封面和合集顺序。连接后，还会核对已有站内媒体文件，以及回复对应的留言。

正式发布时会再次检查。缺失媒体文件等问题需要先处理；缺少封面或简介等情况会作为建议提示。外部网址能否正常访问，仍需要在预览中自行确认。

## 这一轮先记到这里

从页面入口到写作、整理、连续阅读和订阅，这一轮把小站日常使用需要的东西补齐了不少。接下来可以慢慢往里面放真正的生活、学习和作品，让这些角落逐渐有自己的内容。

具体怎样操作，另外整理在了[《小站使用说明书：写作、整理与发布》](/posts/site-guide/)里。以后忘了某个按钮怎么用，就回来翻一翻。
