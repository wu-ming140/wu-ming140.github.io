**先复习，承接昨天学的静态成员**
判断一下：在已经创建 `p1`、`p2` 后，再执行：
```
Phone p3 = p1;

System.out.println(Phone.getCount());
```
**输出多少？`Phone p3 = p1;` 有没有创建第三个手机对象？**

**答案：输出2，没有创建第三个对象**
```
Phone p3 = p1;
```
只是把 `p1` 保存的引用复制给 `p3`，两个变量引用同一个对象。没有执行 `new Phone(...)`，构造方法也就没有执行，`count` 不会增加。

## final
`final` 修饰变量：赋值后不能再重新赋值

```
final int maxScore = 100;

maxScore = 120; // 编译报错
```
普通变量可以修改，`final` 变量赋值后就固定了。
**`static final` 常用来定义类常量**
例如成绩上限：
```
class Student {
    public static final int MAX_SCORE = 100;
}
```
三个修饰符分别表示：
- `public`：允许外部访问。
- `static`：属于类，通过类名访问。
- `final`：赋值后不能重新赋值。
使用：
```
System.out.println(Student.MAX_SCORE); // 100
```
常量名通常使用大写，多个单词用下划线分隔，例如 `MAX_SCORE`。
**`final` 修饰引用变量，固定的是引用**
这一点要结合刚学过的数组理解：
```
final int[] numbers = {10, 20, 30};
```
下面允许：
```
numbers[0] = 99;
```
因为修改的是**数组中的元素**。
下面不允许：
```
numbers = new int[]{7, 8}; // 编译报错
```
因为这是在给 `numbers` **重新赋值，让它引用另一个数组**。
所以：
```
final int[] numbers = {10, 20, 30};
```
表示 `numbers` 始终引用这个数组，**不代表数组里的元素不能修改**。
同样，对手机对象也成立：
```
final Phone p = new Phone("华为", 9999);

p.show();                    // 可以调用方法
p = new Phone("小米", 2999); // 编译报错：不能重新给p赋值
```
如果 `Phone` 提供了修改价格的方法，也仍然可以通过 `p` 修改该对象的价格。


判断这段合法代码的输出：
```
final int[] a = {1, 2, 3};
int[] b = a;

b[0] = 88;

System.out.println(a[0]);
```
这里 **`a` 有 `final`，但 `b` 修改的是数组元素**，最后会输出什么？
`final` 限制的是 `a` 不能重新赋值，数组元素仍然可以修改。
所以输出88

**可以和const类比**
但是要区分基本类型和引用类型

对于基本类型，这两个作用很接近：
```
final int n = 10; // Java
```

```
const int n = 10; // C/C++
```
赋值后，都不能再修改 `n`。
但对于引用：
```
final int[] a = {1, 2, 3};
```
它更接近 C++ 中**指针本身固定**的意思：
```
int data[] = {1, 2, 3};
int* const p = data;

p[0] = 88; // 可以修改指向的元素
// p不能再指向别处
```
对应到 Java：
```
a[0] = 88;               // 可以：修改数组元素
a = new int[]{4, 5, 6};   // 不可以：给a重新赋值
```
**`final` 固定变量保存的值；引用变量保存的是引用，固定引用不等于固定对象内容。**


## 枚举enum
当一个变量只能从几个固定选项中取值时，可以用它。
例如订单状态只有：
```
未付款、已付款、已发货
```
**定义枚举类型**
```
enum OrderStatus {
    UNPAID,
    PAID,
    SHIPPED
}
```
这里：
- `OrderStatus` 是你定义的类型。
- `UNPAID`、`PAID`、`SHIPPED` 是这个类型的三个枚举值。
枚举值通常用大写命名。


```
OrderStatus currentState = OrderStatus.PAID;
```
对照
```
int age = 18;
```
结构完全一样：

|类型|变量名|初始值|
|---|---|---|
|`int`|`age`|`18`|
|`OrderStatus`|`currentState`|`OrderStatus.PAID`|

**创建一个名叫 `currentState` 的变量，类型是 `OrderStatus`，当前值为“已付款”。**

之后可以修改它：
```
currentState = OrderStatus.SHIPPED;
```
再看方法：
```
public static void show(OrderStatus currentState) {
    System.out.println(currentState);
}
```
这里各部分负责不同的事：
- `static`：修饰方法，允许通过类名调用。
- `OrderStatus`：参数的类型。
- `currentState`：参数的名字

 `currentState` **只是变量名，没有特殊语法含义**。


## 继承extends
让一个类复用另一个类已有的成员，并增加自己的功能。

**学生是一种人**，学生可以拥有“人”的姓名和相关方法，再增加“学习”的行为

**父类与子类**
```
class Person {
    public void eat() {
        System.out.println("正在吃饭");
    }
}

class Student extends Person {
    public void study() {
        System.out.println("正在学习");
    }
}
```
这里：
```
class Student extends Person
```
表示 `Student` 继承 `Person`：
- `Person`：父类。
- `Student`：子类。
创建学生对象后：
```
Student s = new Student();

s.eat();   // 使用从父类继承的方法
s.study(); // 使用子类自己定义的方法
```
输出：
```
正在吃饭
正在学习
```
没有在 `Student` 中重新写 `eat()`，它也能使用这个方法。
**加入之前学的封装**

**完整代码**
~~~
class person{
	private String name;
	public void setname(String name)
	{
		this.name=name;
	}
	public String getname()
	{
		return name;
	}
	public void eat()
	{
		System.out.println(name+"在吃饭");
	}
}

class student extends person{
	public void study()
	{
		System.out.println(getname()+"在学习");
		
	}
}

public class study1{
	public static void main(String[] args)
	{
		student s=new student();
		
		s.setname("111");
		
		s.eat();
		s.study();
	}
}

~~~
`Student` 可以使用父类提供的 `setName()`、`getName()` 和 `eat()`。

**父类的 `private` 成员，子类不能直接访问**
注意子类里写的是：
```
System.out.println(getName() + "正在学习");
```
如果改成：
```
System.out.println(name + "正在学习"); // 编译报错
```
就不行，因为 `name` 在 `Person` 中声明为 `private`。

所以要通过父类提供的 `public getName()` 读取姓名。**继承仍然要遵守访问权限。**
另外，Java 的一个类只能直接继承一个父类：
```
class student extends Person {
}
```


## 方法重写
子类重新实现父类已有的方法，让它具有自己的行为

**子类提供自己的实现**
```
class Animal {
    public void eat() {
        System.out.println("动物正在吃东西");
    }
}

class Dog extends Animal {
    @Override
    public void eat() {
        System.out.println("狗正在吃狗粮");
    }
}
```
这里，`Dog` 重新定义了父类的：
```
public void eat()
```
调用：
```
Dog dog = new Dog();
dog.eat();
```
输出：
```
狗正在吃狗粮
```
因为子类重写了 `eat()`，所以调用的是子类提供的实现。

**2．`@Override` 是什么？**
它是一个注解，表示：**这个方法打算重写父类方法，请编译器检查。**
例如不小心把名字拼错：
```
@Override
public void eatt() {
    System.out.println("狗正在吃狗粮");
}
```
编译器会报错，因为父类没有对应的 `eatt()`。
如果没有 `@Override`，这段代码可能被当成新增方法，拼写错误就容易被忽略。因此，**重写方法时建议写上 `@Override`。**


**完整**
~~~
class animal{
	public void eat(){
		System.out.println("在吃");
	}
	
}

class dog extends animal{
	@Override
	public void eat(){
		System.out.println("在吃东西");
	}
}

public class study{
	public static void main(String[] args)
	{
		animal a=new animal();
		dog cat=new dog();
		
		a.eat();
		cat.eat();
	}
}

~~~
父类自己的实现仍然存在；子类对象使用重写后的实现。
**区分“重载”和“重写”**

|概念|典型写法|作用|
|---|---|---|
|重载|`eat()`、`eat(String food)`|同名方法接收不同参数|
|重写|子类重新实现父类的 `eat()`|改变继承来的行为|

例如，在 `dog` 里写：
```
public void eat(String food) {
    System.out.println("正在吃" + food);
}
```

它的参数列表变了，**没有重写父类的无参 `eat()`**，而是形成了重载。

 `final` 也能修饰方法：
```
public final void eat() {
    System.out.println("正在吃东西");
}
```
这样的父类方法，**子类不能重写**。

## super

主要用于两件事：
- 调用父类的方法。
- 调用父类的构造方法。
**`super.eat()`：调用父类的方法实现**
之前子类重写了 `eat()`。如果想先执行父类的代码，再补充自己的行为，可以这样：
```
class Animal {
    public void eat() {
        System.out.println("开始吃东西");
    }
}

class Dog extends Animal {
    @Override
    public void eat() {
        super.eat();
        System.out.println("狗正在吃狗粮");
    }
}
```
调用：
```
Dog dog = new Dog();
dog.eat();
```
输出：
```
开始吃东西
狗正在吃狗粮
```
这里：
```
super.eat();
```
明确调用父类的 `eat()` 实现。
注意，如果在狗的 `eat()` 里面直接写：
```
eat();
```
就会再次调用狗自己的 `eat()`，不断递归调用，最终可能栈溢出。

**`super(...)`：调用父类的构造方法**
给动物加上姓名：
```
class Animal {
    private String name;

    public Animal(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }
}
```
狗继承动物，也需要把姓名初始化好：
```
class Dog extends Animal {
    public Dog(String name) {
        super(name);
    }

    public void bark() {
        System.out.println(getName() + "：汪汪");
    }
}
```
在 `main` 中：
```
Dog dog = new Dog("旺财");
dog.bark();
```
输出：
```
旺财：汪汪
```
创建过程是：
```
new Dog("旺财")
    ↓
进入 Dog 构造方法
    ↓
super(name) 调用 Animal 构造方法
    ↓
父类构造方法初始化 name
    ↓
返回 Dog 构造方法，继续执行
    ↓
对象初始化完成
```
**始终创建的是一个 `Dog` 对象。** 父类构造方法负责初始化这个对象中由父类定义的部分。
**为什么这里要写 `super(name)`？**
如果这样写：
```
public Dog(String name) {
}
```
没有显式调用其他构造方法，编译器会尝试隐式调用父类的无参构造方法，也就是：
```
super();
```
但当前 `Animal` 只有：
```
public Animal(String name)
```
没有无参构造方法，因此会编译报错。
明确写 `super(name)`，就指定了能匹配的父类构造方法。
把这几个写法区分开：

|写法|含义|
|---|---|
|`this.name`|当前对象的成员变量|
|`this(...)`|调用本类的另一个构造方法|
|`super.eat()`|调用父类的 `eat()` 实现|
|`super(...)`|调用父类的构造方法|

**训练**
~~~
class Animal {
    public Animal() {
        System.out.println("Animal构造");
    }
}

class Dog extends Animal {
    public Dog() {
        super();
        System.out.println("Dog构造");
    }
}
~~~
在 `main` 中执行：
```
Dog dog = new Dog();
```
先输出的是animal构造

父类构造方法执行完，再回到子类构造方法

## 多态
继承和方法重写结合

**父类类型的变量，可以引用子类对象**
之前写：
```
Dog dog = new Dog();
```
也可以写成：
```
Animal animal = new Dog();
```
拆开：
```
Animal animal   → 变量声明的类型是 Animal
new Dog()       → 实际创建的对象是 Dog
```
含义是：**把狗当作一种动物来使用。** 实际对象始终是狗。
**调用被重写的实例方法，执行实际对象的实现**
```
class Animal {
    public void eat() {
        System.out.println("动物正在吃东西");
    }
}

class Dog extends Animal {
    @Override
    public void eat() {
        System.out.println("狗正在吃狗粮");
    }
}

class Cat extends Animal {
    @Override
    public void eat() {
        System.out.println("猫正在吃鱼");
    }
}
```
在 `main` 中：
```
Animal a = new Dog();
a.eat(); // 狗正在吃狗粮

a = new Cat();
a.eat(); // 猫正在吃鱼
```
**同一个变量 `a`，调用的都是 `a.eat()`，但它引用的实际对象不同，执行的实现也不同。这就是多态的一种表现。**

**多态的作用**
可以写一个统一的方法，处理不同的动物：
```
public static void feed(Animal animal) {
    animal.eat();
}
```
在 `main` 中调用：
```
feed(new Dog());
feed(new Cat());
```
输出：
```
狗正在吃狗粮
猫正在吃鱼
```
参数类型写的是 `Animal`，所以可以接收 `Dog`、`Cat` 对象
方法内部调用 `eat()` 时，执行各自重写的实现。

**变量能直接调用哪些方法，看声明类型**
假设狗还有一个专属方法：
```
public void bark() {
    System.out.println("汪汪");
}
```
那么：
```
Animal a = new Dog();

a.eat();  // 可以，Animal 声明了 eat()
a.bark(); // 编译报错，Animal 没有声明 bark()
```
目前记住：
- **编译时**：根据变量声明的类型，检查是否有可调用的方法。
- **运行时**：对于被重写的实例方法，根据实际对象选择实现。
这个规则先用于以上正在讨论的实例方法
字段和静态方法不按这套动态选择规则处理。


**练习**
~~~
Animal a = new Cat();
Animal b = new Dog();

feed(a);
feed(b);
~~~
输出  猫吃鱼  狗吃狗粮

**父类引用指向狗时，怎么调用狗特有的 `bark()`？**
**先给 `Dog` 加上专属方法**
```
class Dog extends Animal {
    @Override
    public void eat() {
        System.out.println("狗正在吃狗粮");
    }

    public void bark() {
        System.out.println("汪汪");
    }
}
```
下面仍然不能直接调用：
```
Animal a = new Dog();

a.bark(); // 编译报错：Animal中没有声明bark()
```
虽然实际对象是狗，但编译器根据变量 `a` 声明的类型 `Animal` 检查可调用的方法

**要再向下转型：把引用转换为子类类型**
```
Animal a = new Dog();

Dog dog = (Dog) a;
dog.bark(); // 汪汪
```
这里：
```
Dog dog = (Dog) a;
```
表示将 `a` 保存的引用转换为 `Dog` 类型，再赋给 `dog`。

**没有创建新对象，`a` 和 `dog` 引用的仍然是同一只狗。**
对应的术语是：
```
Animal a = new Dog(); // 向上转型，自动完成
Dog dog = (Dog) a;    // 向下转型，需要显式转换
```

**ai拓展：instanceof**
运算符   用来判断一个引用指向的对象是否属于某个类型
返回boolean值
~~~
对象引用 instanceof 类型名
~~~

**强制转换不能把猫变成狗**
```
Animal a = new Cat();

Dog dog = (Dog) a; // 运行时抛出ClassCastException
```
实际对象是猫，不能转换成狗的引用。
所以，转换之前可以用 **`instanceof`** 判断：
```
Animal a = new Dog();

if (a instanceof Dog) {
    Dog dog = (Dog) a;
    dog.bark();
}
```
a instanceof Dog会得到一个 `boolean`，判断 `a` 引用的对象是否属于 `Dog` 类型或其子类。
如果换成：
```
Animal a = new Cat();
```
判断结果就是 `false`，不会进入分支。
**强制转换改变的是引用的使用类型，实际对象的类型始终由创建它的 `new Dog()` 或 `new Cat()` 决定。**

判断依据是实际对象的类型，不只是变量声明的类型。
和强制转换是两步不同的操作：
```
if (a instanceof Dog) { // 第一步：判断是不是狗
    Dog dog = (Dog) a;  // 第二步：确认之后，进行类型转换
    dog.bark();
}
```
`instanceof` 本身**只做判断，不执行转换，也不创建对象**。


## 抽象类和抽象方法 abstract
**父类可以只规定“要有什么方法”**
之前我们给 `Animal` 写了具体的 `eat()`：
```
public void eat() {
    System.out.println("动物正在吃东西");
}
```
如果希望**每种具体动物都自己实现吃东西的行为**，父类可以只声明方法：
```
public abstract void eat();
```
这叫**抽象方法**：
- 加上 `abstract`。
- 没有方法体，也就是没有 `{ ... }`。
- 末尾写分号 `;`。
包含抽象方法的类，也必须声明为抽象类：
```
abstract class Animal {
    public abstract void eat();
}
```

**普通子类必须实现继承的抽象方法**
```
class Dog extends Animal {
    @Override
    public void eat() {
        System.out.println("狗正在吃狗粮");
    }
}
```
`Dog` 是一个普通的具体类，因此必须实现 `eat()`。如果漏写，就会编译报错。
这里的实现，仍然用方法重写。

**抽象类不能直接创建对象**
```
Animal a = new Animal(); // 编译报错：Animal是抽象类
```
但它仍然可以作为变量或参数的类型：
```
Animal a = new Dog();
a.eat(); // 狗正在吃狗粮
```
这就是多态：变量类型是 `Animal`，实际对象是 `Dog`


**抽象类也可以有普通方法**
它不要求所有方法都是抽象方法：
```
abstract class Animal {
    public abstract void eat();

    public void sleep() {
        System.out.println("正在睡觉");
    }
}

class Dog extends Animal {
    @Override
    public void eat() {
        System.out.println("狗正在吃狗粮");
    }
}

public class study01 {
    public static void main(String[] args) {
        Animal a = new Dog();

        a.eat();
        a.sleep();
    }
}
```
输出：
```
狗正在吃狗粮
正在睡觉
```
这里两种方法各有作用：
```
public abstract void eat();
```
要求具体子类提供自己的实现。
```
public void sleep() {
    System.out.println("正在睡觉");
}
```
父类已经提供实现，子类可以直接继承使用，也可以重写
**抽象类把共同的实现保留下来，把需要子类决定的行为留成抽象方法。**
