## 双指针
通常指用两个下标配合处理数据 不一定是指针
**例题  有序数组找两个数**
给定一个从小到大排列的数组：
```
数组：1 2 4 7 11
目标：9
```
找出两个不同位置的数，使它们之和为 `9`。
用两个下标：
```
1   2   4   7   11
↑               ↑
left           right
```
每次比较 `a[left] + a[right]`：
- 和太小：`left++`，换一个更大的数。
- 和太大：`right--`，换一个更小的数。
- 正好相等：找到答案。

**c++代码实现**
~~~C++
#include<iostream>
void shuangzhizhen(const int a[],int n,int target)
{
	int left=0;
	int right=n-1;
	while(left<right)
	{
		long long sum=(long long)a[left]+a[right];
		if(sum<target)
		{
			left++;
		}
		else if(sum>target)
		{
			right--;
		}
		else
		{
			cout<<"找到了"<<a[left]<<'+'<<a[right]<<'='<<target;
			return;
		}
	}
	cout<<"找不到";


}

int main()
{
	int a[]={1,2,4,7,11};
	shuangzhizhen(a,5,9);
	return 0;
}
//前提是数组有序
~~~

## 滑动窗口
**两个下标通常向右移动**
不仅要维护左右边界  还要维护窗口内信息
~~~
sum;//当前窗口所有元素和

//窗口向右边扩大
sum+=a[right];

//左边缩小
sum-=a[left];
left++;

//左边移动前  要先把离开窗口的元素从sum减掉
~~~

**例题：找和至少为目标值的最短连续子数组**



数组：2 3 1 2 4 3
目标：7

2 3 1 2 → 和为8，长度4
1 2 4   → 和为7，长度3
4 3     → 和为7，长度2

答案2

**要求数组元素都是非负数  目标值>0**
- 向右加入元素，和不会减小。
- 从左移走元素，和不会增大。

思路：
右端加入一个元素   如果窗口的和到了，记录长度
尝试缩小窗口，看看能不能找到更短的
~~~
#include<iostream>
using namespace std;


int min_value(const int a[],int n,int target)
{
	int left=0;
	long long sum=0;
	int best=n+1;//初始成一个不可能的长度
	
	for(int right=0;right<n;right++)
	{
		sum+=a[right];
		//扩大窗口
		
		while(sum>=target)
		{
			int length=right-left+1;
			if(length<best)
			{
				best=length;
			}
			sum-=a[left];//缩小窗口
			left++;
		}
		
		
	}
	if(best==n+1)
	{
		return 0;//找不到
	}
	return best;


}

int main()
{

	int a[]={2,3,1,2,4,3};
	cout<<min_value(a,6,7);


}
~~~
