#### 补充
**左值和右值**
1、名字  2、能不能用&取到内存地址
左值有名字，有固定内存地址，可以用&取（可以理解成我们的变量。？
右值是临时产生的   没有名字  不能取地址
**关键看能不能用&取地址**

**回调**
把一段函数的代码  作为参数   传给另一个函数  让另一个函数在执行的时候调用这个函数的代码（此时是作为参数传入了）
示例
~~~
#include <iostream>

// 定义一个函数
void arr(int result) {
    std::cout << "计算结果: " << result << std::endl;
}

// 定义函数
// 参数：void (*cb)(int) 意思是：我要接收一个接收 int 参数且无返回值的函数（指针），我叫它 cb
void calculate(int a, int b, void (*cb)(int)) {
    int sum = a + b;
    //计算完后，调用传进来的那个函数（执行回调）
    cb(sum); 
}

int main() {
    // 4. 把这个函数的名字（本质是地址）传给 calculate
    calculate(3, 4, arr); 
    return 0;
}
~~~
**现代c++写法   lambda(以下ai拓展的学习）**
用std::function代替   直接传lambda进去
**关于function（是一个类对象）**
**万能函数容器**
里面做了复杂的“类型擦除”和动态内存分配（如果 Lambda 捕获的数据很大）。它的调用速度比直接调用普通函数或 Lambda 要慢一点。**不要在性能极度敏感的循环（比如每秒执行千万次的渲染循环）里大量使用。**

~~~
#include <iostream>
#include <functional> 

// 接收回调，用 std::function<void(int)> 代替了恶心的函数指针
void calculate(int a, int b, std::function<void(int)> cb) {
    int sum = a + b;
    cb(sum);
}

int main() {
    // 直接扔一个 Lambda 进去作为回调
    calculate(3, 4, [](int result) {
        std::cout << "计算完了，结果是: " << result << "\n";
    });
    
    // 你又想换个通知方式？再写个 Lambda 就行！
    calculate(5, 5, [](int result) {
        std::cout << "结果是: " << result << "\n";
    });
}
~~~
`calculate` 这个函数完全不用改代码，在 `main` 里传不同的 Lambda 进去，它就执行不同的通知逻辑。**这就叫回调。**

回调应用   有一个比较典型的是sort函数，第三个函数cmp可以是自己写，也可以直接传lambda
~~~
#include <iostream>
#include <vector>
#include <algorithm> 

int main() {
    std::vector<int> nums = {3, 1, 4, 2};

    // 默认升序
    std::sort(nums.begin(), nums.end()); 
    
    // 降序：通过 Lambda 传递一个“比较规则（回调）”给 sort
    std::sort(nums.begin(), nums.end(), [](int a, int b) {
        return a > b; 
    });
}
~~~
