## 方法调用和栈帧

**方法被调用时候 会建立自己的栈帧**
栈帧：一次方法调用用来保存参数、局部变量等执行信息的空间

~~~java
public class study01 {
    public static void main(String[] args) {
        int number = 10;

        int result = addOne(number);

        System.out.println(number); // 10
        System.out.println(result); // 11
    }

    public static int addOne(int x) {
        x = x + 1;
        return x;
    }
}
~~~
**进入 `main`**
创建属于这次 `main` 调用的栈帧，执行：
```
int number = 10;
```
此时 `main` 中有一个局部变量 `number`，值为 `10`。
**调用 `addOne(number)`**
`main` 等待调用结果，同时为这次 `addOne` 调用建立新的栈帧。
参数 `x` 得到 `number` 的值的副本：

|所属方法|变量|值|
|---|---|---|
|`main`|`number`|`10`|
|`addOne`|`x`|`10`|

**这是两个不同的变量。**
**执行 `x = x + 1`**

|所属方法|变量|值|
|---|---|---|
|`main`|`number`|`10`|
|`addOne`|`x`|`11`|

修改的是 `x`，所以 `number` 仍然为 `10`。
**执行 `return x`**
返回数值 `11`，这次 `addOne` 调用结束，它的栈帧也随之移除。
`main` 继续执行，把返回值赋给 `result`：
```
int result = 11;
```
有两个独立的过程：
- **传参**：把 `number` 的值复制给 `x`。
- **返回**：把计算结果交给调用处，再赋给 `result`。
`return x` 不会把结果自动写回 `number`。如果你希望更新它，需要明确写：
```
number = addOne(number);
```
调用结束后，`number` 才会变成 `11`。

## 数组对象和引用变量和传参
**数组对象在堆中，局部引用变量属于方法的栈帧**
```
int[] a = {10, 20, 30};
```
- **数组对象**：存放三个元素，可以按 Java 的内存模型理解为位于堆中。
- **局部变量 `a`**：保存这个数组的引用，用来找到数组。
`a` 保存的并不是三个元素本身。之前学过：
```
int[] b = a;
```
复制的是引用，因此两者找到的是同一个数组。
**把数组传给方法，复制的也是引用**
```
public class study01 {
    public static void main(String[] args) {
        int[] a = {10, 20, 30};

        change(a);

        System.out.println(a[0]); // 99
    }

    public static void change(int[] numbers) {
        numbers[0] = 99;//修改的是那个共享数组的第一个元素。返回 `main` 后，通过 `a[0]` 也会读到 `99`
    }
}
```
调用时，`a` 的引用值被复制给参数 `numbers`
给参数重新赋值，影响的只是参数自己,和传的实参无关(好像说了和没说一样)

方法结束时，`numbers` 这个局部参数随栈帧移除；**堆中的对象并不会因为方法返回就立刻被销毁**。如果对象不再能被程序通过引用访问，它才可能被垃圾回收。

因此，**Java 始终是值传递**：

`int` 等基本类型数据值修改参数不影响外部变量`int[]` 等引用类型引用值可以修改同一个对象；给参数重新赋值不影响外部变量

**训练**

```
public static void change(int[] numbers) {
    numbers[0] = 99;
    numbers = new int[]{7, 8};
    numbers[0] = 100;
}
```

在 `main` 中：

```
int[] a = {10, 20, 30};

change(a);

System.out.println(a[0]);
System.out.println(a.length);
```
第二个 `3` 对了，**第一个应该是 `99`**。

关键是按顺序看：**第一行已经修改了原数组，后面换数组不会撤销这个修改。**

```
public static void change(int[] numbers) {
    numbers[0] = 99;             // ① 修改原数组
    numbers = new int[]{7, 8};   // ② numbers 改为引用新数组
    numbers[0] = 100;            // ③ 修改新数组
}
```

对应的变化是：

|执行到哪里|`a` 引用的数组|`numbers` 引用的数组|
|---|---|---|
|刚进入方法|`[10, 20, 30]`|同一个原数组|
|执行①之后|`[99, 20, 30]`|同一个原数组|
|执行②之后|`[99, 20, 30]`|新数组 `[7, 8]`|
|执行③之后|`[99, 20, 30]`|新数组 `[100, 8]`|

改元素会改变当前引用的数组；给 `numbers` 重新赋值，只会改变它接下来引用哪个数组

**方法可以返回数组。为什么方法结束了，返回的数组还能继续使用？**

**返回数组的方法，返回类型写 `int[]`**

```
public class study01 {
    public static void main(String[] args) {
        int[] a = createArray();

        System.out.println(a[0]);     // 10
        System.out.println(a.length); // 3
    }

    public static int[] createArray() {
        int[] numbers = {10, 20, 30};
        return numbers;
    }
}
```
返回类型是 `int[]`，表示这个方法返回一个整数数组的引用
return numbers` 返回的是引用值

- 调用 `createArray()`，建立这次调用的栈帧。
- 创建数组对象，局部变量 `numbers` 引用它。
- `return numbers` 把引用值交给调用处。
- `main` 中的 `a` 接收这个引用。


执行完之后，`a` 就引用了方法中创建的数组。
虽然 `createArray` 的栈帧已经移除、局部变量 `numbers` 已经结束生命周期，**数组仍然被 `a` 引用，因此可以继续使用**。
要区分：**局部变量的生命周期，与它引用的对象的生命周期，是两回事。**
**让外面的变量换一个数组”**
之前这样写：
```
public static void change(int[] numbers) {
    numbers = new int[]{7, 8};
}
```
只改变方法内部的参数。
如果希望 `main` 中的 `a` 引用新数组，可以返回新数组，然后明确赋给 `a`：
```
public static int[] createArray() {
    return new int[]{7, 8};
}
```
调用：
```
int[] a = {10, 20, 30};

a = createArray();

System.out.println(a[0]);     // 7
System.out.println(a.length); // 2
```

**真正改变 `a` 的，是 `main` 中的赋值语句 `a = ...`。**

**章节训练**
~~~
public class study01{
    public static void main(String[] args)
    {
        int[] a={2,4,6};
        int[] b=doublecopy(a);
        System.out.println(a[0]);
        System.out.println(b[0]);
    }//创建一个和source长度相同的数组  新数组元素是愿数组的元素的值的两倍
    //返回新数组   保留愿数组内容
    public static int[] doublecopy(int[] source)
    {
        int[] c=new int[source.length];//初始化新数组  长度是那个
        for(int i=0;i<c.length;i++)
        {
            c[i]=source[i]*2;
        }
        return c;
    }
}
~~~


## 面向对象基础（类 封装 继承 多态 接口）

**类和对象**
类：定义这一类对象有什么数据、能做什么
学生有姓名、年龄，也可以介绍自己：
```
class Student {
    String name;
    int age;

    void introduce() {
        System.out.println("我叫" + name + "，今年" + age + "岁");
    }
}
```
- `Student`：类名，也是一种自己定义的类型。
- `name`、`age`：**成员变量**，保存每个学生的数据。
- `introduce()`：**实例方法**，描述学生可以执行的行为。

联系 C 的 `struct` 理解；Java 的类还可以把相关方法（函数）一起定义进去。

**对象：根据类创建出来的具体实例**
```
Student s1 = new Student();
```

```
Student s1;       // 声明一个 Student 类型的引用变量
s1 = new Student(); // 创建学生对象，让 s1 引用它
```
`new Student()` 创建对象，其中 `Student()` 是构造方法调用
和下面数组有相似的
```
int[] a = new int[3];
```

**变量保存引用，通过引用使用创建出来的对象。**
**用点号访问成员变量、调用方法**

```
s1.name = "小明";//访问成员变量
s1.age = 18;

s1.introduce();//调用示例方法
```
`introduce()` 没写 `static`，这里通过具体对象的引用来调用。执行 `s1.introduce()` 时，方法里使用的是 **`s1` 所引用对象的姓名和年龄**。

**两个对象，各自保存数据**
~~~java
class Student {
    String name;
    int age;

    void introduce() {
        System.out.println("我叫" + name + "，今年" + age + "岁");
    }
}

public class study01 {
    public static void main(String[] args) {
        Student s1 = new Student();
        s1.name = "小明";
        s1.age = 18;

        Student s2 = new Student();
        s2.name = "小红";
        s2.age = 20;//创建了两个独立对象

        s1.introduce();
        s2.introduce();

        s1.age = 19;

        System.out.println(s1.age); // 19
        System.out.println(s2.age); // 20
    }
}
~~~
**成员变量有默认值**。刚创建的学生对象，如果还没赋值：

```
Student s = new Student();

System.out.println(s.name); // null
System.out.println(s.age);  // 0
```

**private和封装:  让对象通过自己提供的方法管理数据**

比如手机价格，如果允许直接赋值：
```
phone.price = -100;
```
就可能出现不合理的数据。我们可以把价格设为私有，再通过方法检查修改是否合法。
**`private`：限制外部直接访问**
```
class Phone {
    private double price;
}
```
这样，在 `main` 中就不能直接读写：
```
Phone phone = new Phone();
phone.price = 2999;             // 编译报错
System.out.println(phone.price); // 编译报错
```

**即使 `Phone` 和 `main` 写在同一个文件里，也不能这样访问。** `private` 成员只能由声明它的类内部直接访问。

**提供方法，控制修改和读取**

```
class Phone {
    private double price;

    public void setPrice(double newPrice) {
        if (newPrice >= 0) {
            price = newPrice;
        } else {
            System.out.println("价格不能为负数");
        }
    }

    public double getPrice() {
        return price;
    }
}
```

两个方法各自负责：
```
setPrice(...) // 修改价格，修改前检查
getPrice()    // 返回当前价格
```
方法前的 `public` 表示允许外部访问这个方法。


**完整代码实现**
~~~java
class Phone{
	private double price;
	public void setprice(double newprice)
	{
		if(newprice>=0)
		{
			price=newprice;
		}
		else
		{
			System.out.println("价格不能负数");
		}
	}
	public double getprice()
	{
		return price;
	}

}
public class study{
	public static void main(String[] args)
	{
		Phone phone=new Phone();
		phone.setprice(2999);
		System.out.println(phone.getprice());
		
		phone.setprice(-100);//不合法所以不执行price=newprice
		System.out.println(phone.getprice());
	}
}

~~~
封装的意义就在这里：对象把数据保存起来，并通过提供的方法控制外部如何操作这些数据
