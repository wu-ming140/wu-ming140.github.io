**堆和栈这里主要是学和内存那块的，不是算法（）**
## 栈 
内存小   速度快  可以自动管理  
函数进入时分配，函数退出时自动销毁
用于存放局部变量、函数参数

## 堆
内存很大，速度较慢   要手动管理（比如用new申请，delete释放
**申请内存后一定要释放  否则会内存泄漏**
堆主要存放那种生命周期需要很长、或者体积很大、大小在运行时才能确定的数据
**尽量少用new和delete**
~~~
栈上的数组int arr[10];   //函数结束会自动销毁  大小是固定

堆上数组 int* arr=new int[10];
//必须手动释放   delete[] arr;
//大小可以在运行时决定
~~~
**推荐用vector代替堆数组和栈数组 
ai提到智能指针  unique_ptr   管理堆内存  可以自动释放**

## 指针和错误
指针是指针变量   存内存地址
在定义的时候就要先初始化   可以指向nullptr

**野指针**
~~~
int* p; // 定义了一个指针，但没有初始化
*p = 10; //p 指向了随机的内存地址，直接导致程序崩溃
~~~
**悬垂指针**
~~~
int* p = new int(10);
delete p; // 内存释放
*p = 20;  //不能这样写   因为前面已经delete释放了指针
~~~
**在delete释放后   一定要把指针指向空 p=nullptr**

**内存泄漏  ：new申请后忘记释放  会导致内存泄漏**

## 引用
（之前学过）
~~~
int a = 10;
int& ref = a; // ref 就是 a 的外号
ref = 20;     // a 变成了 20
~~~
要先初始化
引用不占用额外内存  类似起别名
**函数传参和返回值，优先用引用（尤其是 const 引用）
尽量不用指针，因为危险**

引用要有对象  不能改变指向 也不能是空   没有多级引用（本质变量的别名）
指针可以改指向  （本质是存内存地址的变量）

## 左值和右值
**左值**：**有名字、有固定内存地址**的表达式。你能用 `&` 取到它的地址。
普通变量 `int a = 10;` 里的 `a`。

**右值 ：暂时的，临时的、的表达式。无法获取地址（只关注数据）
临时的计算结果也是右值  a+1
~~~
int a = 10;        // a 是左值（有名字、有固定地址的变量），10 是右值（字面量，临时的）
int b = a + 5;     // b 是左值，a + 5 是右值（算出来的临时结果，马上就销毁）
~~~


&&可以存储右值   并不是复制   所以性能会更好
